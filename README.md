# Афиша Башкортостана

Первый рабочий этап проекта для «Кибер 102». Каталог культурных событий с открытыми источниками, веб-интерфейсом, REST API и Telegram-ботом. Данные организаторов пока не получены. Текущий каталог охватывает Уфу. Заявочный уровень будет указан после проверки всех его требований.

## Запуск

Нужен Node.js 24 LTS (24.15+) или Docker.

```bash
npm ci
npm run refresh
npm start
```

Откройте [каталог](http://localhost:3000), [API](http://localhost:3000/docs) или [виджет](http://localhost:3000/widget?city=Уфа). Обновление источников занимает около минуты. Повторный запуск `npm run refresh` обновляет каталог. Уже сохранённые карточки доступны, пока идёт загрузка или недоступен один из источников.

Docker запускает сайт и начинает обновление пустой базы в фоне.

```bash
docker compose up --build
docker compose exec app npm run refresh
```

Файл SQLite хранится в томе `catalog`. При локальном запуске база создаётся в `data/catalog.sqlite`. Переменная `CATALOG_PATH` задаёт другой путь.

## Telegram

Скопируйте `.env.example` в `.env`, укажите `BOT_TOKEN` от BotFather, затем перезапустите приложение. `PUBLIC_SITE_URL` добавляет ссылки на сайт, если задан публичный HTTPS-адрес. Поиск, карточки и подписки используют ту же базу. Отписка удаляет подписки пользователя. До отписки хранятся только идентификатор чата и выбранные фильтры. Бот принимает команды в личных чатах.

## Источники и данные

- [Управление культуры Уфы](https://kulturaufa.ru/category/afishi/). Публичный JSON API возвращает анонсы. Импорт принимает объявления с однозначными датой, временем и площадкой.
- [Афиша Уфа](https://afisha-ufa.ru/). Сбор читает общедоступные страницы, проверяет правила для обхода и разбирает структурированные данные карточек.
- Исходные записи хранятся отдельно от каталога. Если цена или возраст неизвестны, фильтр по соответствующему полю исключает такую запись. Отменённые события доступны по прямой ссылке с отметкой. Поиск их скрывает.
- Собранные данные покрывают только проверенные на момент обновления карточки. Запуск обновления остаётся отдельной операцией. Продакшен-расписание, расширение географии, рассылка подписок и подтверждение условий использования источников относятся к следующим этапам.

## Проверка REST API

Запустите приложение по инструкции выше. Аутентификация нужна только для записей в каталог.

| Метод и URL | Заголовки или тело | Ожидаемый результат |
|---|---|---|
| `GET http://localhost:3000/health` | Без тела | `200`, `{"status":"ok"}` |
| `GET http://localhost:3000/api/v1/events?city=Уфа&limit=5` | Без тела | `200`, `events`, `page`, `limit`, `total` |
| `GET http://localhost:3000/api/v1/events/<id>` | Возьмите `id` из выдачи | `200`, карточка и её источники. Неизвестный ID возвращает `404`. |
| `GET http://localhost:3000/api/v1/events?maxPrice=-1` | Без тела | `400`, код `invalid_filter` |
| `POST http://localhost:3000/api/v1/admin/import` | `Authorization: Bearer <ADMIN_TOKEN>`, `Content-Type: application/json` или `text/csv` | `200`, счётчики `added`, `updated`, `unchanged` и причины отклонения записей. С настроенным токеном запрос без него получает `401`. |
| `PATCH http://localhost:3000/api/v1/admin/events/<id>` | Те же заголовки, JSON `{"status":"cancelled"}` | `200`. Запись исчезает из поиска, её карточка возвращает `status: "cancelled"`. |

Укажите собственный `ADMIN_TOKEN` в `.env` и перезапустите приложение для проверки записи. Без токена запись отключена и возвращает `503`. Для JSON-импорта передайте массив записей. Каждая запись содержит `title`, `category`, `startsAt` с часовым поясом, `city`, `venue`, `sourceName`, `sourceUrl` и статус `published`, `draft` или `cancelled`. CSV использует те же имена колонок. Для обновлений передавайте стабильный `sourceKey`. Отправка такой же записи повторно увеличивает `unchanged`. Пример тела для отрицательной проверки с валидным токеном

```json
[
  {
    "title": "",
    "category": "concert",
    "startsAt": "2026-11-20T19:00:00+05:00",
    "city": "Уфа",
    "venue": "",
    "sourceName": "Управление культуры Уфы",
    "sourceUrl": "https://kulturaufa.ru/category/afishi/",
    "status": "draft"
  }
]
```

Ожидается `200` с одной записью в `rejected`. Для ручного ввода одной записи используйте `POST http://localhost:3000/api/v1/admin/events` с одним объектом JSON и теми же заголовками. Пустые обязательные поля возвращают `400`.

Для проверки успешного импорта передайте запись из ответа `GET /api/v1/events` с приведёнными ниже полями. Тестовое обновление оставьте черновиком, чтобы оно не попало в выдачу. Название, площадку и время скопируйте из выбранной карточки, а ссылку возьмите из `sources[0].url`.

```json
[
  {
    "sourceKey": "postman-draft",
    "title": "<название из карточки>",
    "category": "<категория из карточки>",
    "startsAt": "<startsAt из карточки>",
    "city": "<город из карточки>",
    "venue": "<площадка из карточки>",
    "sourceName": "<sources[0].name из карточки>",
    "sourceUrl": "<sources[0].url из карточки>",
    "status": "draft"
  }
]
```

Ожидается `200` с пустым `rejected`. Повторная отправка возвращает `unchanged: 1`.

## Разработка

`src/catalog.ts` хранит события, источники, изменения и подписки. `src/sources.ts` загружает внешние источники. `src/api.ts`, `src/web.ts` и `src/bot.ts` используют общий каталог. Веб-страницы серверные и работают без клиентского JavaScript.

```bash
npm test
npm run typecheck
```
