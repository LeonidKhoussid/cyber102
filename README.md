# Афиша Башкортостана

Поиск культурных событий по вопросу на русском языке. Можно указать город, день, возраст ребёнка, бюджет на группу, время окончания и предел поездки. В диалоге работают уточнения и продолжения, например «А подешевле?», «А что ещё?» и «А в воскресенье?».

## Запуск

Node.js 24.15+.

```bash
npm ci
npm run refresh
npm start
```

- Веб-приложение работает на [localhost:3000](http://localhost:3000).
- Fastify API работает на [localhost:3001](http://localhost:3001/health).
- `npm start` запускает API и Vite отдельными процессами. Для раздельного запуска используйте `npm run start:api` и `npm run dev:web`.
- `npm run build` собирает веб-приложение в `apps/web/dist`.

```bash
docker compose up --build
docker compose exec api npm run refresh
```

В Docker веб-приложение раздаёт Nginx. Fastify работает в отдельном контейнере и владеет томом SQLite. Пустая база начинает обновляться в фоне при первом запуске. Повторное обновление запускается вручную.

## Архитектура

- `apps/web` содержит React и Vite. Поиск открывается на `/`. Каталог, карточки, виджет и API-справка доступны на `/catalog`, `/events/:id`, `/widget` и `/docs`.
- `apps/api` содержит Fastify, SQLite, поиск, импорт и сбор данных.
- `apps/bot` содержит отдельный TypeScript-процесс grammY. Бот обращается к Fastify по HTTP.
- `packages/contracts` содержит типы и общие категории.

Для Telegram скопируйте `.env.example` в `.env`, задайте `BOT_TOKEN` от BotFather и одинаковый `BOT_API_TOKEN` у бота и API. Перезапустите API и запустите `npm run start:bot`. В Docker используйте `docker compose --profile telegram up --build`. `PUBLIC_SITE_URL` добавляет публичные HTTPS-ссылки на сайт. Подписки хранят идентификатор чата и фильтры до отписки. Рассылка пока не включена.

## Как работает подбор

Локальный разбор русских запросов работает сразу. Для дополнительного разбора произвольных формулировок можно настроить OpenAI-совместимый сервис через `DISCOVERY_MODEL`, `DISCOVERY_MODEL_KEY` и при необходимости `DISCOVERY_MODEL_BASE`. Сервис получает текст запроса и текущие условия. Подбор, цены, ссылки и объяснения остаются на стороне каталога. При отказе модели работает локальный разбор.

Бюджет на группу считается по опубликованной начальной цене билета. Доступность билетов проверяйте у источника. Записи с неизвестной ценой, возрастом или окончанием не выдаются как подтверждённые совпадения по соответствующему ограничению. Если задан предел поездки, укажите точку отправления координатами или названием площадки с координатами в каталоге. Для оценки поездки на машине настройте `ROUTING_ORIGIN` на сервер OSRM. Сервер маршрутов получает координаты, а приложение показывает оценку без данных о пробках.

Источники текущего каталога

- [Управление культуры Уфы](https://kulturaufa.ru/category/afishi/) через публичный JSON API.
- [Афиша Уфа](https://afisha-ufa.ru/) через открытые страницы событий.
- [Русский драматический театр Стерлитамака](https://rusdramteatr.ru/afisha) через афишу и карточки театра. Карточки содержат даты и возраст, часто продолжительность. Цена остаётся неизвестной, когда площадка её не публикует.

Обновление проверяет ограниченную выборку. Данные организаторов пока не получены. Покрытие региона, модерация, планировщик дня и формальная оценка уровня хакатона остаются отдельными задачами.

## Postman

Сначала запустите приложение по инструкции выше.

| Метод и URL | Заголовки и тело | Ожидаемый ответ |
|---|---|---|
| `POST http://localhost:3001/api/v1/discover` | `Content-Type: application/json`, `{"message":"Куда сходить в Уфе в эти выходные?"}` | `200`, поля `status`, `message`, `constraints`, `events`, `suggestions`, `context`. Состав выдачи зависит от даты и базы. |
| `POST http://localhost:3001/api/v1/discover` | Тот же заголовок, `{"message":"А подешевле?","context":{...}}`, где объект `context` взят из первого ответа | `200`. Город и даты сохраняются. Порог цены привязан к предыдущей подборке. |
| `POST http://localhost:3001/api/v1/discover` | Тот же заголовок, `{"message":""}` | `400`, `invalid_message`. |
| `GET http://localhost:3001/api/v1/events?limit=5` | Без токена и тела | `200`, список событий и параметры страницы. |
| `PUT http://localhost:3001/api/v1/bot/subscriptions` | `Authorization: Bearer <BOT_API_TOKEN>`, `Content-Type: application/json`, `{"subscriber":"1","city":"Уфа","category":"concert"}` | `200`, `{"saved":true}`. При настроенном токене без авторизации возвращается `401`. |
| `DELETE http://localhost:3001/api/v1/bot/subscriptions` | Те же заголовки, `{"subscriber":"1"}` | `200`, `{"removed":1}` после PUT, затем `{"removed":0}`. |

Административный импорт требует `ADMIN_TOKEN`. Отправьте массив JSON на `POST http://localhost:3001/api/v1/admin/import` с заголовками `Authorization: Bearer <ADMIN_TOKEN>` и `Content-Type: application/json`. Записи содержат `title`, `category`, `startsAt` с часовым поясом, `city`, `venue`, `sourceName`, `sourceUrl`, `status` и по возможности стабильный `sourceKey`. Для CSV используйте те же колонки и `Content-Type: text/csv`. Ответ `200` содержит счётчики импорта и причины отклонений. Повтор записи увеличивает `unchanged`.

`npm test` запускает проверки API, каталога, импорта и Telegram на контролируемых данных. `npm run typecheck` проверяет все рабочие области.
